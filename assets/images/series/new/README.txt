CRICPRO Reusable Assets - One by One
=====================================

This package includes:
1. core_clean_assets/  -> previously cleaned reusable Flutter assets
2. auto_extracted/     -> one-by-one extracted elements from the generated card asset sheets

Auto extracted component counts:
- sheet1_tournament: 26 assets
- sheet2_bilateral: 15 assets
- sheet3_league: 19 assets
- sheet4_misc: 32 assets

Files are PNGs. See asset_manifest.csv/json for file list and bounding boxes.
