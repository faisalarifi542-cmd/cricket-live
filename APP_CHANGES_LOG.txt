BUGS FIXED:
  BUG-A  Offline shows "No live matches" instead of offline state
    Root cause: _loadTabMatches() caught all errors → returned [] empty list.
                _HomeMatchList FutureBuilder never checked snapshot.hasError.
    Fix:        _loadTabMatches() now propagates network errors (no outer catch).
                _loadHero() throws when ALL sources fail + items empty.
                _refresh() assigns _tabFuture directly (not Future.value(await)).
                FutureBuilder checks snapshot.hasError → shows CricOfflineCard.
                New CricOfflineCard widget: wifi_off icon, Retry button, premium theme-aware.

  BUG-B  Pull refresh after reconnect stuck on old state
    Root cause: _refresh() awaited loadTabMatches then wrapped in Future.value —
                error lost before reaching FutureBuilder.
    Fix:        _refresh() assigns Future directly to _tabFuture in setState.

  BUG-C  Live Player page background still dark in light mode
    Root cause: live_screen_dark_background.png rendered unconditionally as
                Positioned.fill behind entire screen.
    Fix:        Wrapped in if (c.isDark) — hidden in light mode.
                Cyan radial glow wrapped in Opacity(isDark ? 1.0 : 0.3).

  BUG-D  Team names/scores invisible on result card in light mode
    Root cause: Colors.white hardcoded for team name + score text.
    Fix:        c.isDark ? Colors.white : c.text for both.

  BUG-E  Selected quality card dark navy in light mode
    Root cause: Gradient end stop hardcoded 0xff0b2b4a.
    Fix:        c.isDark ? Color(0xff0b2b4a) : c.card2.

  BUG-F  Repository cache returning stale/empty on network error
    Root cause: _cached() returned [] on non-forced read if no cache + error.
    Fix:        forceRefresh=true removes stale entry before fetch, rethrows
                on error. Non-forced reads still serve stale (resilient).

  BUG-G  Duplicate in-flight requests
    Root cause: No dedup for concurrent same-key callers.
    Fix:        _inflight map added. Concurrent callers join existing Future.

  BUG-H  Match Details tab reverts to previous tab after 5s poll
    Root cause: _restoreScrollAndTab() forced setState(tab = oldTab) post-frame.
    Fix:        Renamed to _restoreScroll(). Tab restore removed. Scroll only.

  BUG-I  Stream defaults to FHD not SD
    Root cause: Default quality selection priority was highest first.
    Fix:        SD → HD → FHD priority. Falls back to qualities.first.

  BUG-J  Quality card labels inconsistent (FHD showed real height e.g. 1080p)
    Root cause: _createQualityFromResolution stored real parsed height.
    Fix:        Fixed display labels: FHD=720p, HD=480p, SD=288p per spec.

  BUG-M  Quality bottom sheet FHD shows 1080p, cards show 720p
    Root cause: _createQualityFromResolution stored real height ('${height}p').

    Fix:        _createQualityFromResolution now stores fixed display labels:
                FHD=720p, HD=480p, SD=288p in resolution field used by sheet.

  BUG-N  Modal dim too heavy in light mode
    Root cause: No barrierColor set → Flutter default Colors.black54.

    Root cause: _qualityOptionsFor() returned deduped 3-bucket list only.

                _showQualitySelector uses _hlsAllVariants when available.
                Fullscreen player sheet also uses _hlsAllVariants.
                Card highlight fixed: URL-only match (not URL+code) so card
                highlights correctly when raw variant selected from sheet.
                Sheet selected highlight also URL-only match.
