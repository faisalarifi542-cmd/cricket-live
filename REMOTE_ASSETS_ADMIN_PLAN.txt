PHASE A — Backend (cricket-api)
---------------------------------
1. Create DB table: app_assets
   Columns:
     id          SERIAL PRIMARY KEY
     asset_key   VARCHAR(100) UNIQUE NOT NULL
     url         TEXT NOT NULL
     theme       VARCHAR(10) DEFAULT 'both'  -- 'light'|'dark'|'both'
     version     VARCHAR(40)                 -- hash or semver
     active      BOOLEAN DEFAULT true
     created_at  TIMESTAMP DEFAULT now()
     updated_at  TIMESTAMP DEFAULT now()

2. Migration file: cricket-api/migrations/xxx_create_app_assets.sql

3. Endpoints:
   GET  /app/assets          — public, no auth, returns active assets array
   POST /admin/assets        — admin auth, create/update asset
   PUT  /admin/assets/:key   — admin auth, update by key
   DEL  /admin/assets/:key   — admin auth, deactivate (soft delete)

4. Response shape:
   {
     "assets": [
       {
         "key": "home_hero_bg_dark",
         "url": "https://cdn.example.com/assets/home_hero_dark_v2.png",
         "theme": "dark",
         "version": "abc123",
         "updatedAt": "2026-06-12T10:00:00Z"
       }
     ]
   }

5. Include assets in /app/config response optionally for single-request init.

PHASE C — Flutter (lib/)
--------------------------
1. New file: lib/services/remote_assets_service.dart
   - Fetches GET /app/assets on startup
   - Stores Map<String, RemoteAsset> in memory
   - Persists to local SharedPreferences/Hive as JSON (offline cache)
   - Exposes: RemoteAssetsService.of(context).url(key, theme)

2. New widget: RemoteOrLocalImage
   - Takes: assetKey, localFallback, fit, ...
   - Checks RemoteAssetsService for URL
   - If found: CachedNetworkImage (already used in app or add package)
   - If not found or fails: Image.asset(localFallback)
   - Respects light/dark theme variant

3. Replace current hardcoded Image.asset calls for movable assets:
   Before:
     Image.asset('assets/images/live_stream/backgrounds/live_screen_dark_background.png')
   After:
     RemoteOrLocalImage(
       assetKey: 'live_player_bg_dark',
       localFallback: 'assets/images/live_stream/backgrounds/live_screen_dark_background.png',
     )

4. Asset versioning/cache busting:
   - CachedNetworkImage cacheKey = '${key}_${version}'
   - On version change → stale cache auto-evicted
