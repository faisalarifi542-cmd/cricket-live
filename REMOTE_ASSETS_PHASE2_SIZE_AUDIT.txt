4. MUST STAY BUNDLED FOREVER (never remote)
--------------------------------------------------------------------------------
  - App launcher icon + adaptive icon (android/ios native).
  - Splash screen image.
  - Fonts (fonts/, pubspec fonts:).
  - light_mode/* clean overlays (small; they ARE the light fallback art).
  - Placeholder avatars / generic team + player fallback portraits
    (team_*.png, player_*.png, series/venues/venue_generic.png).
  - Essential UI icons, status badges, glass/overlay effects that are tiny.
  - Any asset < ~50 KB (network round-trip not worth it; risk > reward).

6. EXPECTED APK SIZE REDUCTION
--------------------------------------------------------------------------------
  Current APK (arm64, release): ~51 MB. assets/images raw: 26 MB.
  (Note: PNGs are already partially compressed inside the APK; raw KB is an
  upper bound on savings, real APK savings are smaller.)

  Phase 2 wiring alone removes NOTHING from the bundle — it only enables remote
  override. Size drops in Phase 4 when originals are archived and replaced by
  compressed fallbacks.

  Realistic staged savings once Phase 4 completes for the candidates above:
    - Replace ~13 MB of large decorative PNGs with ~1.2 MB compressed JPG/WebP
      fallbacks  => ~11–12 MB raw asset reduction.
    - Estimated APK reduction: ~8–10 MB (51 MB -> ~41–43 MB), arm64 release.
    - AAB delivered size to users is smaller again due to per-device splitting.

  This is an UPPER-BOUND estimate; actual measured numbers go in the Phase 5
  report after --analyze-size runs.


RISK NOTES
----------
  - StadiumImage is shared: one wiring change touches many screens. Verify all
    StadiumImage screens (home/matches/schedule/series) in both themes.
  - match_details dark header uses raw Image.asset (different path) — wire and
    test separately.
  - Light mode uses clean light_mode/* art via LightAsset.forStadium(); remote
    light keys must not regress that. Keep light fallbacks bundled.
  - NEVER ship an asset with no bundled fallback. Offline + remote-404 must show
    the bundled image (RemoteOrLocalImage already guarantees this).
