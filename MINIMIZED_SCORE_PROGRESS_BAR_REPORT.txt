** CRITICAL GAP **
There is NO structured target / runs-needed / balls-remaining / chase field.
- "Need X from Y" only exists as FREE TEXT in statusText / resultText.
- Live-center payload has current_run_rate + required_run_rate as STRINGS only
  (md_info.dart:49-50). No numeric target, no runs-needed, no balls-left.
- No explicit batting-team boolean (inferred from batTeam/bowlTeam JSON keys,
  cricket_match.dart:120-121).

IMPLICATION for the reference design ("Need 26 from 22", "171 Target",
progress = 145/171): these NUMBERS are not directly in the model. We must
PARSE them from statusText with a regex, with safe fallback. See section 4.

--------------------------------------------------------------------------------
4. PROGRESS CALCULATION — HOW IT WILL WORK
--------------------------------------------------------------------------------
Because there is no numeric target field, derive via layered parsing:

A) Parse chase line from statusText (regex, case-insensitive):
     "need (\d+) (?:runs? )?(?:from|in|off) (\d+)"  -> needRuns, needBalls
   If matched AND match isLive -> show "Need {needRuns} from {needBalls}".

B) Parse current runs from the batting team's score text:
     teamXScoreText "145/3 (16.2 OV)" -> currentRuns=145
   (regex ^(\d+))

C) Target:
   target = currentRuns + needRuns   (when chase line parsed)
   progress = (currentRuns / target).clamp(0.0, 1.0)
   left label  = "{battingShort} {runs}/{wkts}"
   right label = "{target} Target"

D) Fallbacks (per spec rules):
   - statusText has no "need ..." -> hide chase equation + hide target labels.
   - isFinished -> show resultText/statusText instead of "Need X from Y";
     progress bar full or hidden.
   - Not a chase / no target -> hide progress bar (do NOT invent a target).
   - Missing score numbers -> hide progress, keep team scores as raw text.

Which team is batting (for left progress label): pick the team whose score
text contains the higher/most-recent overs, OR the team referenced in the
parsed chase line; default to teamA if ambiguous. Kept defensive — label only,
never blocks render.
